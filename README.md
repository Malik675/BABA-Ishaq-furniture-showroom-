# BABA Ishaq Furniture — Virtual Showroom V2

A cinematic, showroom-style responsive homepage using the supplied furniture photos.

Features:
- Virtual showroom entrance scene
- Perspective room, walls, floor, lights and display pedestals
- Mouse movement parallax on desktop
- Mobile-friendly layout
- Furniture collection
- Direct call and WhatsApp buttons
- Free static hosting compatible with GitHub Pages

Upload all files to a public GitHub repository and enable GitHub Pages.
